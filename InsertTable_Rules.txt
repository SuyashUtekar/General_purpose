bank_inspection_reports — 40 rows

CAMELS distribution — realistic for Indian banking:

Rating 1 → 10%  (SBI, HDFC, ICICI — strong banks)
Rating 2 → 35%  (Most PSBs — adequate)
Rating 3 → 30%  (Weaker PSBs, some PVT)
Rating 4 → 15%  (Yes Bank, UCBs — under watch)
Rating 5 →  5%  (PM UCB — near failure)

Component scores must be internally consistent:

# If CAMELS overall = 4, then at least 3 components must be 4 or 5
# Asset quality (NPA-linked) score must match npa_accounts data

# Banks with high NPA → low asset_score
# BNK-002 (PNB) has 80 NPA accounts → asset_score = 4
# BNK-001 (SBI) has 20 NPA accounts → asset_score = 2

def get_asset_score(bank_id, npa_accounts_df):
    npa_count = npa_accounts_df[npa_accounts_df.bank_id == bank_id].shape[0]
    if npa_count > 50:  return 5
    if npa_count > 30:  return 4
    if npa_count > 15:  return 3
    if npa_count > 5:   return 2
    return 1

Seasonal patterns make this look very real:

import numpy as np

def generate_upi_volume(bank_id, month):
    base_volumes = {
      "BNK-001": 45_000_000,   # SBI — highest UPI volume
      "BNK-004": 38_000_000,   # HDFC
      "BNK-005": 32_000_000,   # ICICI
      "BNK-009": 180_000,      # UCB — much lower
    }
    base = base_volumes.get(bank_id, 5_000_000)

    # Festival months spike — Oct, Nov (Diwali), Jan (New Year)
    festival_months = [10, 11, 1]
    multiplier = 1.35 if month.month in festival_months else 1.0

    # Add realistic noise
    noise = np.random.normal(1.0, 0.08)
    return int(base * multiplier * noise)

# Failed transaction % — must be < 0.5% for healthy banks
# Cyber incidents — 0-2 for healthy, 3-8 for WATCH banks
